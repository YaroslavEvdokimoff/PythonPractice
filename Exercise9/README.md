# Итераторы и генераторы (Задание 9)

Данный проект содержит программные решения для работы с бесконечными последовательностями на Python с использованием механизмов итераторов (классы с методами `__iter__` и `__next__`) и генераторов (функции с ключевым словом `yield`). 

В репозитории также представлен пакет из **10 автоматических unit-тестов** для комплексной проверки корректности работы алгоритмов.

## Содержимое проекта

Проект включает в себя реализацию трех основных компонентов:
1. **Класс `Fibo`** — бесконечный итератор чисел Фибоначчи (`0, 1, 1, 2, 3, 5, 8...`). В соответствии с жесткими требованиями задания, вычисление элементов происходит **строго с использованием операции сложения**, без применения встроенных математических функций или возведения в степень.
2. **Генератор `integers`** — бесконечный генератор неотрицательных целых чисел по возрастанию, начинающийся с `0`.
3. **Генератор `primes`** — бесконечный генератор простых чисел (`2, 3, 5, 7, 11...`). Реализован по оптимизированному алгоритму: проверка текущего кандидата на простоту осуществляется путем деления исключительно на уже найденные ранее простые числа, что значительно сокращает количество избыточных вычислений.

## Структура автоматических тестов

В коде реализовано **10 изолированных тестов** на базе встроенного фреймворка `unittest`:
* **Тесты 1–3 (`Fibo`):** Проверка правильности начального ряда, независимости состояний разных экземпляров класса и соответствия протоколу итератора Python.
* **Тесты 4–6 (`integers`):** Проверка старта с нуля, генерации последовательного числового ряда без пропусков и валидация типа возвращаемого объекта (`types.GeneratorType`).
* **Тесты 7–9 (`primes`):** Контроль первых элементов выборки, проверка корректного игнорирования составных чисел (таких как 4, 9, 15) и вычисление отдаленного простого числа (31).
* **Тест 10 (Бесконечность):** Валидация долгосрочной работы (более 100 циклов подряд) на отсутствие преждевременного исключения `StopIteration`.

## Требования

* **Python:** Версия 3.6 или выше.
* **Зависимости:** Не требуются (используются только стандартные библиотеки Python).

Все компоненты и тесты объединены в одном файле `ex_9.py`. Чтобы запустить тестирование и проверить корректность работы всех алгоритмов, выполните в терминале следующую команду:
