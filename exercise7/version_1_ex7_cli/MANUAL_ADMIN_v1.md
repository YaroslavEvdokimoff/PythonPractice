# РУКОВОДСТВО АДМИНИСТРАТОРА ПРИЛОЖЕНИЯ «Система управления фермерскими рынками» (текстовый режим, без ООП, данные в файлах)

Интерактивное консольное приложение (CLI) на языке Python для поиска, фильтрации, сортировки и рецензирования фермерских рынков США. Программа спроектирована с использованием принципов **функционального программирования (ФП)**, обеспечивая предсказуемость данных и чистоту бизнес-логики.

Данный документ содержит служебную спецификацию, необходимую для проверки целостности структуры, развёртывания и ручного тестирования консольной версии приложения (Версия 1: CLI) в рамках проекта `Система управления фермерскими рынками`.

## 1. Системные требования и зависимости

- **Операционная система:** Microsoft Windows 10 / 11, macOS, Linux.
- **Интерпретатор:** Python версии **3.10** или выше.
- **Внешние библиотеки:** Программа использует исключительно встроенные библиотеки языка (`math`, `sys`, `os`, `csv`). Спецификация `requirements.txt` является пустой (0 КБ), так как установка сторонних пакетов через `pip` не требуется.

## 3. Конфигурация путей к данным и синхронизация полей

Импорт информации о фермерских рынках настроен динамически. Переменная `CSV_PATH` в модуле `main.py` указывает на относительный путь `../data/Export.csv` с автоматическим фолбеком на имя файла в текущей директории. 

**Спецификация регистров полей:**
Слой чтения данных `io_handler.py` считывает заголовки таблиц «как есть». Все ключевые поля бизнес-логики в модулях `main.py` и `core.py` жестко синхронизированы с регистром букв в исходном файле `Export.csv`:
- Поля локации и координат обрабатываются строго в нижнем регистре: `city`, `state`, `zip`, `street`, `x`, `y`.
- Поля идентификатора и наименования обрабатываются в исходном верхнем регистре: `FMID`, `MarketName`.

## 4. Верификация ядра (Модульное тестирование)

Перед запуском основного интерфейса администратор или проверяющий может запустить автоматическое изолированное тестирование функций расчёта. 

Для этого откройте Командную строку (cmd) в папке `version_1_ex7_cli` и выполните:
```bash
python core.py
```

### Спецификация встроенных тестов:
Программа выполнит встроенные проверки через механизм `assert`, тестируя:
1. Точность расчёта дистанции по формуле гаверсинусов.
2. Корректность вычисления среднего рейтинга и защиту от деления на ноль для новых рынков.
3. Многокритериальную фильтрацию, гео-поиск по радиусу и регистронезависимость текстовых полей.
4. Принцип иммутабельности ФП (исходные списки при генерации отзывов не мутируют).

В случае успешного прохождения в консоль выведется статус:  
`УСПЕХ: Все встроенные ассерты ядра успешно пройдены!`.

## 5. Инициализация сессии пользователя

Запуск пользовательского интерфейса (командная строка `Команда>`) со сквозной поддержкой пагинации по 5 элементов на страницу осуществляется кликом по пакетному файлу **`run_Ex7_v1.bat`** либо вручную командой `python main.py` из папки `version_1_ex7_cli`. 

Пакетный файл `run_Ex7_v1.bat` содержит встроенную команду `pause`, предотвращающую закрытие окна терминала при возникновении непредвиденных системных исключений.
