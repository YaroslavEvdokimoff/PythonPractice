# РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ ПРИЛОЖЕНИЯ «Система управления фермерскими рынками» (текстовый режим, без ООП, данные в файлах)

Эта программа позволяет находить фермерские рынки в США, смотреть подробную информацию о них, читать и оставлять отзывы, а также сортировать их по удобным критериям.

## 🚀 Как запустить программу

Программа работает через командную строку (консоль). Чтобы её запустить, вы можете использовать любой из двух способов:

### Способ 1 (Самый простой)
Просто зайдите в папку `version_1_ex7_cli` и дважды кликните по файлу **`run_Ex7_v1.bat`**. Программа запустится автоматически в отдельном черном окне.

### Способ 2 (Вручную через консоль)
1. Откройте Терминал или Командную строку в папке `version_1_ex7_cli` (на Windows: нажмите на адресную строку вверху папки, введите `cmd` и нажмите Enter).
2. Введите команду и нажмите Enter:
   ```bash
   python main.py
   ```

## 🕹️ Как пользоваться (Все команды и кнопки)

Программа общается с вами с помощью текстовых запросов. Вы вводите команду и нажимаете **Enter**.

### 1. Главное меню
Эти команды можно вводить в строке `Команда ➔` сразу после запуска программы:
- **`list`** — показать список вообще всех рынков в базе данных.
- **`search`** — запустить умный поиск. Программа сама по очереди спросит у вас Город, Штат и Индекс. Также она предложит ввести координаты, чтобы найти рынки поблизости (например, не дальше 30 миль от вас). Если какой-то пункт поиска вам не нужен, просто нажмите **Enter**, чтобы пропустить его.
- **`delete <номер_ID>`** — удалить рынок из списка по его ID (например: `delete 1011171`).
- **`help`** — снова показать список главных команд.
- **`exit`** — выйти из программы.

### 2. Просмотр списков (Страницы)
Когда вы ввели `list` или `search`, программа показывает рынки порциями — по 5 штук на экран. В строке `Навигация` вы можете вводить:
- **`N`** (или `n`) — перелистнуть на **следующую** страницу.
- **`P`** (или `p`) — вернуться на **предыдущую** страницу.
- **`sort`** — отсортировать этот список. Программа спросит, как сортировать: `1` — по оценкам пользователей, `2` — по названию города, `3` — по расстоянию от вас (если при поиске вы вводили координаты). Затем программа спросит направление: `1` — от большего к меньшему, `2` — от меньшего к большему.
- **`view <номер>`** — открыть карточку рынка под номером от 1 до 5 **на текущей странице** (например: `view 2`).
- **`B`** (или `b`) — закрыть список и вернуться в Главное меню.

### 3. Внутри карточки рынка
Когда вы открыли конкретный рынок через команду `view`, вы увидите его точный адрес, координаты и отзывы других людей. Вам доступны две кнопки:
- **`1`** — написать свой отзыв. Программа попросит ввести ваше Имя, Фамилию, поставить оценку от 1 до 5 звезд и написать текст отзыва (текст можно пропустить, нажав Enter). Оценка сразу повлияет на средний рейтинг рынка.
- **`0`** — закрыть карточку и вернуться назад к страницам списка.

## 🧪 Как проверить, что всё работает правильно?

В программу встроена автоматическая система самопроверки. Она мгновенно тестирует правильность расчёта расстояний и выставления оценок. Чтобы её запустить, введите в консоли внутри папки `version_1_ex7_cli`:
```bash
python core.py
```
Если всё в порядке, вы увидите надпись: `УСПЕХ: Все встроенные ассерты ядра успешно пройдены!`.
