# 👤 РУКОВОДСТВО ПОЛЬЗОВАТЕЛЯ ПРИЛОЖЕНИЯ «Система управления фермерскими рынками» (ВЕРСИЯ 2: GUI, ООП, данные в БД)

## 1. Назначение и возможности приложения
Приложение предоставляет удобный графический интерфейс для работы с базой данных фермерских рынков. Программа позволяет выполнять следующие операции:
* Находить рынки по текстовым критериям (город, штат, почтовый индекс).
* Выполнять точный гео-локационный поиск рынков в определенном радиусе (в милях) от указанных координат.
* Управлять сортировкой списков и просматривать их по страницам.
* Изучать подробные карточки рынков, читать отзывы посетителей с удобным скроллингом и оставлять собственные рецензии.
* Безвозвратно удалять устаревшие или неактуальные записи рынков.

## 2. Описание графического интерфейса
Главное окно приложения имеет размер 1000x650 пикселей и разделено на 4 основные зоны:
1. **Верхняя панель фильтров:** Текстовые поля для ввода города, штата, ZIP-индекса, а также координат (широта, долгота) и радиуса поиска в милях. Содержит кнопки «Поиск» и «Сбросить».
2. **Панель управления (Центр):** Выпадающие списки для настройки сортировки рынков и кнопка удаления записи.
3. **Таблица рынков (Treeview):** Главный список, где отображаются идентификатор рынка (FMID), название, город, штат, расстояние в милях, средний рейтинг (в звездах ★) и количество отзывов.
4. **Нижний пагинатор:** Кнопки «◀ Назад» и «Вперед ▶» для полистного перелистывания страниц (по 15 записей на одной странице).

## 3. Инструкция по эксплуатации функций

### 3.1. Текстовый поиск и сброс фильтров
* Введите название интересующего вас города в поле **«Город»** (например, `Boston`) или сокращение в поле **«Штат»** (например, `MA`) и нажмите кнопку **«Поиск»**. Список в таблице мгновенно обновится.
* Чтобы очистить все поля ввода и снова показать полный список всех рынков, нажмите кнопку **«Сбросить»**.

### 3.2. Поиск рынков по радиусу (в милях)
1. Введите географические координаты в поля **«Широта (Lat)»** и **«Долгота (Lon)»** десятичной дробью (например: широта `42.36`, долгота `-71.05`).
2. Введите максимальное расстояние в поле **«Радиус (миль)»** (например, `50`).
3. Нажмите кнопку **«Поиск»**. 
*Программа автоматически рассчитает расстояние до каждого рынка и выведет только те, которые попали в указанную зону. При вводе некорректных координат (например, широты 150 при норме от -90 до 90) приложение заблокирует запрос и покажет окно с ошибкой валидации.*

### 3.3. Просмотр деталей и добавление отзывов
* **Открытие карточки:** Чтобы открыть полную информацию о фермерском рынке, совершите **двойной клик мыши** по нужной строке в главной таблице.
* **Просмотр отзывов:** В открывшемся окне отобразится лента отзывов. Окно снабжено **вертикальной полосой прокрутки (скроллбаром)**, с помощью которой можно пролистать и прочитать любое количество рецензий.
* **Добавление отзыва:** В нижней части карточки введите ваше Имя, Фамилию, выберите оценку от 1 до 5 звезд в выпадающем списке и напишите текст комментария. После нажатия кнопки **«Отправить рецензию»** средний рейтинг рынка в таблице главного окна пересчитается автоматически.

### 3.4. Удаление рынка
Если какой-то рынок закрылся, выберите его в главной таблице одним кликом мыши и нажмите кнопку **«Удалить выбранный рынок»**. Подтвердите действие во всплывающем окне для безвозвратного удаления записи.

## 4. Порядок запуска для пользователя

* 🛠️ **`run_Ex7_v2.bat`**
