##  Версия 2: ООП + СУБД + GUI


###  Слой данных и СУБД
* **База данных**: Реляционная СУБД **SQLite**. Данные изолированы в файле `data/markets.db`.
* **Архитектура**: Реализован паттерн *Repository* (класс `DatabaseManager`), который преобразует строки СУБД в жестко типизированные ООП-объекты классов `Market`, `User`, `Review`.
* **Связи данных**: Реализована реляционная схема «Один ко многим» между рынками и рецензиями с поддержкой **каскадного удаления (`ON DELETE CASCADE`)**. При удалении рынка СУБД автоматически очищает все связанные отзывы.
* **Оптимизация**: Расчет гео-расстояний (в милях по формуле гаверсинусов), фильтрация и пагинация перенесены с уровня Python-кода напрямую в оптимизированные SQL-запросы СУБД.

###  Руководство администратора по Версии 2

#### 1. Первоначальный импорт данных (Миграция)
Перед первым запуском графического интерфейса необходимо перенести плоские записи из `Export.csv` в базу данных. Перейдите в папку `version_2_oop_gui/` и выполните автоматический скрипт миграции:
```bash
python migrations.py
```
*Скрипт автоматически создаст схему таблиц, настроит внешние ключи и пачками (bulk) загрузит все 1679 записей рынков.*

#### 2. Запуск приложения
Запуск настольного оконного интерфейса осуществляется командой:
```bash
python app.py
```

#### 3. Автоматизированное тестирование (Фреймворк unittest)
Для проверки стабильности СУБД и каскадных связей развернут изолированный пакет тестов, использующий базу данных прямо в оперативной памяти (`:memory:`). Запуск тестов:
runtests.bat

###  Руководство пользователя по графическому интерфейсу

Графическая оболочка построена на фреймворке `Tkinter/ttk` и разделена на логические зоны:

1. **Панель многокритериального поиска (Сверху)**:
   * Позволяет вводить Город, Штат или ZIP-индекс.
   * **Ограничение дальности**: При вводе Широты, Долготы и Максимального радиуса в милях, таблица мгновенно отсекает удаленные рынки и выводит столбец расчетной дистанции. Нажмите кнопку **«Поиск»** для применения или **«Сбросить»** для очистки полей.
2. **Панель управления сортировкой (Посередине)**:
   * Выпадающий список позволяет распределять рынки по *Имени*, *Рейтингу*, *Городу/Штату* или *Удаленности*.
   * Второй выпадающий список задает направление: **Возрастание (Мин -> Макс)** или **Убывание (Макс -> Мин)**. Сортировка применяется мгновенно ко всему объему базы данных.
3. **Главная интерактивная таблица (По центру)**:
   * Выводит данные страницами (по 15 элементов для предотвращения лагов интерфейса).
   * **Удаление записи**: Выделите любой рынок кликом мыши и нажмите кнопку **«Удалить выбранный рынок»** справа. Запись со всеми отзывами каскадно сотрется из СУБД.
   * **Переход к деталям**: Сделайте **двойной клик** по любой строке таблицы фермерского рынка.
4. **Модальное окно карточки рынка**:
   * Открывается поверх главного окна и блокирует его до закрытия.
   * Выводит полные сведения о локации, точный адрес, среднюю оценку и прокручиваемую текстовую ленту рецензий других пользователей.
   * **Добавление рецензии**: Заполните обязательные поля *Имя* и *Фамилия*, выберите оценку от *1 до 5 звезд* в выпадающем списке, наберите текст отзыва и нажмите **«Отправить рецензию»**. Карточка обновится, а при её закрытии главное окно автоматически пересчитает средний балл рынка в общей таблице.
5. **Панель навигации (Снизу)**:
   * Кнопки **«Назад»** и **«Вперед»** позволяют мгновенно перелистывать страницы каталога. Информационная строка показывает текущую страницу и общее количество найденных записей в СУБД.
