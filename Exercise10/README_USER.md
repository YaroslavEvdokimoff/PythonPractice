### 1. Обзор и назначение
Приложение предоставляет полноценную графическую симуляцию классической игры «Морской бой». Поддерживается одиночная игра против встроенного искусственного интеллекта (ИИ) и соревновательный режим для двух человек за одним монитором (Hotseat) с надежной защитой от подглядывания.

### 2. Быстрый запуск игры
Вам не нужно устанавливать сторонние программы или вводить команды в консоль. Запуск игры осуществляется «в один клик» с помощью готовых файлов автоматического старта:

* **Если у вас Windows:** Просто найдите в папке игры и запустите двойным щелчком мыши файл **`deploy_windows.bat`**.
* **Если у вас Linux:** Запустите файл **`deploy_linux.sh`**.

*Скрипт автоматически проверит систему, проведет внутреннее тестирование стабильности кода и откроет игровое окно.* 

При первом запуске игра сама создаст файлы настроек (`config.json`) и сохранения статистики (`highscores.json`).

### 3. Игровой интерфейс
Главное окно имеет следующую структуру разделов:

```text
+-----------------------------------------------------------+

|                          МЕНЮ                             |
+-----------------------------------------------------------+

|               ИНФОРМАЦИОННАЯ ПАНЕЛЬ (ТЕКУЩИЙ ХОД)         |
+-----------------------------+-----------------------------+

|          ВАШЕ ПОЛЕ          |       ПОЛЕ ПРОТИВНИКА       |
|    (Зеленые - ваш флот)     |    (Интерактивные атаки)    |
|                             |                             |
|  [~][~][~][~][~][~][~][~]   |  [.][.][X][.][.][.][.][.]   |
|  [~][X][~][~][~][~][~][~]   |  [.][.][•][.][.][.][.][.]   |
+-----------------------------+-----------------------------+
```

### 4. Описание функций и механик
* **Умная автогенерация флота:** Каждая партия начинается со случайной расстановки кораблей. Флот состоит строго из 10 судов (1 линкор — 4 палубы, 2 крейсера — 3 палубы, 3 эсминца — 2 палубы, 4 катера — 1 палуба). Встроенный алгоритм гарантирует расстановку по правилам: корабли не пересекаются и никогда не соприкасаются друг с другом углами или бортами.
* **Механика ведения огня:** Выстрел выполняется нажатием левой кнопки мыши (ЛКМ) по правому игровому полю. 
  * Попадание (`X`) окрашивает клетку в красный цвет и сохраняет право хода за текущим игроком.
  * Промах (`•`) окрашивает клетку в серый цвет и плавно передает ход оппоненту или компьютеру.
* **Автоматическое обведение (Автопромах):** При полном уничтожении любого корабля (как вашего, так и корабля противника) игра самостоятельно рассчитывает его контуры и расставляет точки (`•`) во всех клетках по его периметру. Это избавляет вас от необходимости вручную обстреливать заведомо пустые клетки вокруг потопленного судна.
* **Экран настроек:** Доступен через верхнее меню. Позволяет налету менять размер окна, переключать режим игры (против ПК или вдвоем) и менять сложность компьютера. Цвета сетки и элементов автоматически подстраиваются под выбранную тему оформления.
* **Таблица рекордов:** Находится в меню игры. Ведет независимый автоматический учет побед для Икрока 1, Игрока 2 и Компьютера, сортируя участников по количеству набранных очков.

### 5. Режим Hotseat (Вдвоем за экраном)
Для честной игры вдвоем за одним компьютером реализована система конфиденциальности. После того как текущий игрок совершает промах, на игровом поле отображается точка выстрела, а через короткую анимационную паузу (600 миллисекунд) поле полностью перекрывается плотной экранной ширмой:

```text
+-----------------------------------------------------------+

|                    ПЕРЕДАЧА УПРАВЛЕНИЯ                    |
|                                                           |
|        Внимание! Убедитесь, что соперник отвернулся       |
|                                                           |
|               [ Кнопка: Я готов, показать поле ]          |
+-----------------------------------------------------------+
```
В это время интерфейс блокируется от случайных нажатий. Новый игрок занимает место перед монитором, нажимает кнопку **«Я готов, показать поле»**, ширма закрывается, и игра отображает обновленную диспозицию полей исключительно для его хода. Это полностью исключает возможность подглядывания за флотом соперника.
